### 1.1 루브릭의 정의와 두 필수 요소 (1장, 인쇄 19–38)

| 책이 말하는 것 | 위치 | 설계에 반영 |
|---|---|---|
| 루브릭은 **평가요소** + **평가요소별 수준별 수행 기술**로 정의된다. 판단(evaluative)이 아니라 기술(descriptive)이어야 하며, 채점은 수행을 기술과 "연결"하는 행위다. | 인쇄 19–22, 36 | 단계 D의 "행동·대상·질의 특징을 담은 기술", 평정 용어(우수/보통/미흡)만으로 칸을 채우지 않는 규칙 |
| 수행(과정·결과물)은 학습 성과의 **지표**일 뿐 학습 성과 자체가 아니다. 한 과제는 여러 가능한 수행 중 한 표본이다. | 인쇄 20–21 | 단계 C 정렬표의 "성취기준의 요구 → 이번 과제에서 볼 증거" 분리 |
| 정답·오답이 명확한 문항에는 루브릭이 필요 없다. 질의 정도를 볼 때만 루브릭이다. | 인쇄 21 | 이분 판정이 적절한 기능은 통과/재수행 등 별도 도구 |
| 분석적/총체적, 일반적/특정 과업형의 장단점 비교. 교실에서는 대부분 **분석적·일반적**이 학습에 유리하다. 특정 과업형은 채점 지침 기능은 좋지만 사전 공유·자기점검·형성평가에 쓸 수 없다. 총체적 루브릭도 여전히 평가요소와 관찰에 기반해야 한다. | 인쇄 22–30 | 단계 D 기본 제안 = 분석적 루브릭; 총체적 선택 시 이유 설명; 정답 공개가 문제되는 세부 채점 메모는 교사용 분리 |
| 같은 종류의 과제에 같은 루브릭을 반복 사용해야 학생이 "좋은 수행의 일반적 특성"을 배운다. | 인쇄 28–29, 31–32 | 반복 사용 목적이면 일반적 질적 기준 우선 |
| 학생이 만든 평가요소, 루브릭 자기평가의 효과 연구 소개(Andrade 등, Ross 등, Hafner). | 인쇄 33–35 | 학습 활용 모드의 근거; 단 스킬 자체의 효과 근거는 아님 |

### 1.2 흔한 오해와 실수 (2장, 인쇄 37–52)

책이 정리한 "일반 교사가 만드는 채점도구의 결점"(Goldberg & Roswell 연구 인용, 인쇄 39)과 저자의 사례 분석에서 뽑은 오류 유형이다. `DESIGN.md` 7절 점검표의 원천이다.

| 오류 유형 | 책의 설명 | 위치 |
|---|---|---|
| 과제와 학습 성과의 혼동 | 루브릭이 과제 지시사항 표가 된다. 보드게임 만들기 활동이 사회과 "규칙 제정" 목표의 증거를 내지 못한 사례. 과제 기반 평가요소는 "지시 따르기·착한 학생"에 대한 정보만 준다. | 인쇄 38–43 |
| 여러 내용 영역을 분리하지 않고 한꺼번에 채점 | 측정하려는 학습 성과가 섞인다. | 인쇄 39 |
| 무관한 요소 채점 | 깔끔함·색상·표지·꾸밈. | 인쇄 39, 44–48 |
| 개수 세기 | "정보 6개 = 4점, 4–5개 = 3점". 숙련의 증거 대신 유무·개수만 본다. 학습 습관(과제 완료 빈도 등)이나 타자 오탈자처럼 수치가 목표 자체인 예외는 인정한다. | 인쇄 39, 44–48 |
| 학생이 알지 못했던 것을 채점 | 사전에 안내되지 않은 조건을 채점에 포함. | 인쇄 39 |
| 결과물 채점 ≠ 학습 채점 | "주 포스터" 사례: 최고점을 받아도 무엇을 이해했는지 교사가 알 수 없다. | 인쇄 44–48 |
| 평정 척도를 루브릭이라 부름 | 평가요소 옆에 우수/좋음/보통/미흡만 붙인 표, 웃는 얼굴 척도. 판단적 척도는 루브릭의 핵심 이점(관찰→기술 연결)을 버린다. | 인쇄 49–51 |
| 순응(compliance)을 배움으로 오인 | 요구사항 준수용 도구는 체크리스트로 분리하면 되고, 그것 자체는 잘못이 아니다. | 인쇄 42–43, 46–47 |

옮긴이의 말에도 국내 사례가 있다. 영어 에세이 루브릭에 내용 요소 없이 제출 여부·어법 오류 개수만 있는 경우, 사회과 루브릭에 평가요소 5개를 한 칸에 묶고 "모두 만족 4점, 2개 만족 3점"으로 기술한 경우(인쇄 7). 검증 사례 E05, E06, E08의 모델이다.

### 1.3 효과적인 루브릭 제작 (3장, 인쇄 53–80)

**평가요소 선정 질문**(인쇄 56): "학생 과제의 어떤 특성이 이 성취기준에 명시된 지식이나 능력을 학습했다는 증거를 제공하는가?" 하나의 성취기준에는 다양한 과제가 가능하므로, 과제마다 달라지는 특징이 아니라 **모든 과제에 공통으로 나타나는 배움의 특성**을 평가요소로 삼는다.

바람직한 평가요소의 6가지 특징(표 3.1, 인쇄 55): 적절함(성취기준·수업목표의 한 측면), 정의 가능, 관찰 가능(보거나 들을 수 있음), 서로 구별됨(중복 없음), 완전함(합치면 학습 성과 전체), 수준의 연속선상에서 기술 가능. 이미 습득한 하위 기능(예: 고교 실험보고서의 문장 쓰기)은 Sadler의 "잠재적 평가요소"로 두고 루브릭에 넣지 않는다(인쇄 54–55).

**수행 수준 기술 질문**(인쇄 59): "각 평가요소에서 학생 과제물은 높은 수준부터 낮은 수준까지 어떻게 다른 모습인가?"

바람직한 수준 기술의 특징(표 3.2, 인쇄 61): 기술적, 명확, 전 범위 포괄(나오지 않을 것 같은 하위 수준도 포함), 수준 간 구별 가능(예시 작품과 연결 가능), 목표 수준이 성취기준의 기대와 일치, **같은 요소를 수준마다 기술**(상은 타당성, 중은 개수, 하는 제출 여부처럼 축이 바뀌면 안 됨).

수준 수와 시작점(인쇄 57–59): 유의미한 질적 차이를 기술할 수 있는 만큼. 단순 기능은 2수준도 가능. 4–5수준이 흔하지만 규범은 아니다. 채점 제약에 맞추려 평가요소·기술을 왜곡하지 말고, 루브릭은 충실히 만든 뒤 성적 반영 방법을 따로 설계한다(11장 참조). 대부분 학생이 도달하길 바라는 **목표 수준(능숙)을 먼저 쓰고** 위아래로 조정하는 방법과 최상위부터 내려오는 방법이 있다. 성취기준 기반이면 "우수"는 기대 초과다.

추론의 정도(인쇄 67–70): 관찰 기술도 완전히 객관적일 수는 없다. "문법 오류 5개"처럼 추론을 없애려다 전문적 판단의 여지를 없애면 안 된다. 오류 3개인 복잡한 글이 오류 1개인 단문 글보다 나을 수 있다. → 7절 "중요한 질을 잃지 않았는가".

성공 방식의 다양성(인쇄 59–61): 잘 만든 일반적 루브릭은 수행 방식을 지나치게 제한하지 않는다. "루브릭에 없으니 안 해도 된다"는 학생 반응은 체크리스트형 루브릭의 문제다. → 7절 "다양한 성공 방식".

설계 접근법(인쇄 62–66): 하향식(성취기준·개념 틀에서 출발, 일반 루브릭 작성 → 특정 목표로 조정 → 시범 적용 후 수정)과 상향식(학생 작품을 상·중·하로 분류 → 분류 이유를 구체적으로 기술 → 공통 특성을 평가요소로 추출 → 수준 기술). 스킬의 "새로 만들기"는 하향식, "기존 표 개선·채점 기준 맞추기"는 상향식 절차를 차용한다.

**개선 사례**(인쇄 70–78, 표 3.4→3.5): 3학년 생애주기 포스터 루브릭 수정. 수정 원칙 세 가지 — 구성·형식 요소(제목, 전반적 모습)를 빼서 학습 습관 도구로 옮김, 점수를 능숙도 수준으로 바꿈, 개수 세기를 실질적 기술로 바꿈. 수정 후 한 요소("순서")에는 "우수" 칸이 없다. 목표 도달이 그 요소의 최고 모습이면 억지로 상위 칸을 만들지 않는다. 개수 세기를 없애면 오히려 정확도가 올라간다(동물마다 단계 수가 다르고 베낀 정보를 세지 않게 됨). → 6절 개선 절차, 단계 D "모든 요소에 억지로 기대 이상을 만들지 않음", 검증 사례 E05·E06.

### 1.4 일반적 루브릭, 특정 과업형, 능숙도 기반 (4–6장, 인쇄 81–137)

- 4장: 6+1 특성 글쓰기, 수학 문제 해결, 서면 보고서, 창의성 루브릭. 수학 문제 해결에서는 전략적 지식과 수학적 의사소통이 내용 지식과 같은 비중의 일반 평가요소가 되었다(인쇄 81). "창의성" 루브릭이 실제로는 예술적 표현·꾸밈 루브릭인 경우가 많다(인쇄 82). → 9절 예술·수학 행.
- 5장: 특정 과업형 루브릭과 항목별 채점표는 정답·필수 개념이 정해진 채점에만 쓴다.
- 6장: 능숙도 기반 루브릭과 성취기준 기반 채점. 같은 능숙도 척도를 여러 과제에 일관되게 쓰는 설계.

이 장들의 실제 루브릭 표는 저작권 대상이므로 스킬에 복제하지 않는다. 구조적 아이디어만 사용한다.

### 1.5 체크리스트와 평정 척도 (7장, 인쇄 138–147)

체크리스트는 유무 판정(마침표가 있는가), 지시사항 준수, "비행 전 점검"에 적합하다(인쇄 138–139). 평정 척도(빈도 척도)는 학습 습관·행동·과제수행 태도에 적합하다(인쇄 140–141). 둘 다 **루브릭이 아니며 질을 평가하지 않는다**. → 7절 "형식 조건은 분리", 6절 개선 옵션 "별도 체크리스트".

### 1.6 교과 사례 (8장, 인쇄 149–160)

- 초등 소리 내어 읽기 유창성(인쇄 149–153): 교사가 루브릭 이해를 위해 학습목표 공유, 시범, 평가요소 설명을 했다. 성적 계산법 설명은 하지 않았다(인쇄 159 확인 문제).
- 중학교 과학 실험 보고서(인쇄 154–155): 어떤 수준에도 도달하지 못한 모둠에도 루브릭이 개선 방향을 알려주었다.
- 고등학교 용접(인쇄 156–158, 표 8.3): 외형, 슬래그 제거, 폭·두께, 완결성, 스패터, 용입 등 **직무 품질 기준을 관찰 가능한 언어로 기술**한 4수준 루브릭. 용접을 모르는 저자에게도 학습목표가 무엇인지 알려주었다. 이 사례는 "수치·정확성·안전이 목표인 교과에서는 정량 기준이 정당하다"는 7절 예외 규칙과 9절 직업 전문교과 행의 근거다. 표 자체는 노스다코타 교사의 허락 하 수록물이므로 복제하지 않는다.

### 1.7 형성평가: 학습목표 공유 (9장, 인쇄 165–181)

"이해 기반 수행(performance of understanding)"은 학생이 배워야 할 것을 보여주고, 배움을 발달시키고, 점검 증거를 제공한다. 용어 찾기 퍼즐은 이해 기반 수행이 아니다(인쇄 165). 학생이 루브릭을 이해하는지 확인하는 전략: 헷갈리는 점 직접 묻기, 자신의 언어로 다시 쓰기("루브릭 번역가"), 짝과 설명하며 과제 전·중·후에 점검, 학생과 함께 만들기(예시 작품 → 잘된 점·부족한 점 브레인스토밍 → 배움의 속성으로 분류 → 평가요소 합의 → 우수 수행부터 기술하고 단계적으로 낮춤 → 예시에 적용해 수정), 예시 작품과 수준 연결(인쇄 166–176). → 단계 F, 학습 활용 모드.

### 1.8 형성평가: 피드백과 자기평가 (10장, 인쇄 182–199)

형성평가는 성장이 실제로 일어나야 형성적이다(인쇄 180). 교사 피드백은 같은 루브릭에 도달 수준을 표시하고 특이사항만 짧게 덧붙인다. 피드백은 채점 전이 가장 효과적이다(인쇄 181–182, 202). 자기평가·목표 설정·동료 피드백 절차가 이어진다. → 단계 F "피드백 뒤 수정할 한 부분", 검증 사례 E24·E26.

### 1.9 채점 (11장, 인쇄 201–225)

| 책이 말하는 것 | 위치 | 설계에 반영 |
|---|---|---|

| 성적표 산출 전에 (1) 무엇을 합치는가, (2) 같은 척도인가, (3) 성적이 무엇을 의미하는가를 정한다. 다른 척도(4점, 6점, 백분율)를 그대로 평균하면 "사과와 오렌지" 오류다. 성적표 척도로 먼저 변환한 뒤 합친다. 성취기준별 기록이면 최근 증거에 비중을 둘 수 있다. | 인쇄 205–215 | 단계 E, 11절 채점·활용 묶음 |

### 1.10 국내 맥락 (옮긴이의 말, 인쇄 6–9)

번역진은 상대평가·민원 부담이 큰 국내 현실에서 공정성·신뢰성을 먼저 걱정하게 되지만, 평가의 최우선 질문은 "이 평가가 학생의 배움을 어떻게 지원하는가"라고 정리한다. 스킬이 배점 요구를 존중하면서도 정렬·증거·기술을 먼저 다루는 순서(1절)의 배경이다.

## 2. DOK(Depth of Knowledge) 조사

조사 담당 하위 에이전트의 보고를 검토·요약했다. 자료 서지와 해시는 [출처 대장](source-ledger.md) B-1~B-9.

### 2.1 핵심 결론

**DOK는 채점 루브릭이 아니다.** 개발자 측 공식 자료(WebbAlign DOK Primer, 2025, p.2)가 DOK는 채점 루브릭, 개인의 사고 깊이 측정, 교수·학습의 위계가 아니며, 높은 DOK가 더 중요한 목표를 뜻하지도 않는다고 명시한다. 따라서 DOK 1–4를 루브릭의 미흡–우수나 1–4점에 대응시키지 않는다. DOK는 **성취기준과 과제가 요구하는 인지적 복잡성**을 검토하는 도구로, 루브릭은 **그 과제에서 드러난 수행의 질**을 기술하는 도구로 분리한다(`DESIGN.md` 8절).

### 2.2 자료별 확인 내용

### 2.3 한계

- 위 자료는 과제의 인지적 요구 분석의 유용성과 난도·복잡성 구분을 뒷받침한다. **DOK를 반영한 AI 생성 루브릭이 한국 학생의 학습·전이·채점 신뢰도를 높인다는 인과 근거는 확인하지 못했다.** 이는 구현 후 현장 검증(E28) 대상이다.
- 예술·체육·직업 실무의 운동 기능·안전·품질·상황 대응 전체에 대한 DOK의 직접 타당화 자료는 확보하지 못했다. 이 영역은 사고 요구가 분명한 부분에만 제한적으로 적용한다(`DESIGN.md` 9절 마지막 문단).
- Webb 2007 논문은 유료 본문을 확보하지 않았다.

### 3.2 설계에 반영한 발견

1. **초등 원문 오염.** `[2건01-01]` 본문에 내용체계표의 다른 열이 섞여 있다. 별책15 공식 PDF 45쪽(인쇄 39쪽)의 정상 문장("나의 몸을 긍정적으로 인식하고 건강 증진을 위한 신체 활동에 안전하게 참여한다.")과 대조했다. `[2건]` 9건 모두 혼입 징후가 있으나 전수 정정하지는 않았다. README의 "전수 검증"을 정확성 보증으로 쓰지 않는다. → 원 반환값/공식 대조값/근거 쪽/검증일 분리 보관, `verificationStatus` 필드.
2. **판본 ≠ 적용 시점.** 2026-1호 고시의 초1·2 적용은 2028-03-01이다. 위 건강한 생활 기준을 2026학년도 초등 수업 기준으로 자동 추천하면 안 된다. 2022-33호의 중3·고3 시행은 2027-03-01이므로 2026학년도 중3·고3에 2022 교육과정을 자동 적용해도 안 된다. → 입력 계약에 `사용 학년도 + 학교급 + 학년 + 과목 + 판본`, 검증 사례 E17·E18.
3. **중등 일부개정 미반영.** 저장소가 2026-1호 별책3·4 미반영을 스스로 고지한다. 다만 이것만으로 기존 문장이 모두 틀렸다고 판단하지도 않는다.
4. **코드 충돌.** 중등에서 다른 과목이 같은 코드를 공유하는 사례 11종(예: `[12스문01-01]` = 스페인어권 문화 / 스포츠 문화). → 식별자는 `서버 + 판본 + 과목 + code`, 내부적으로 `key` 보존. 중등 `get_standard`는 `subject` 인자를 받는다. 검증 사례 E15.
5. **요약·파생 데이터와 공식 본문 분리.** 초등 구조 JSON의 과거 `officialTextIncluded:false` 필드가 남아 있지만 서버가 별도 본문 파일을 `officialText`로 결합한다. 중등·직업의 `summaryKind: mechanical-derivative`, 관찰 증거·평가 발문은 기계 파생 후보다. **이 파생 항목을 평가요소로 복사하면 오류가 증폭된다.** → 10절 "summary·기계 파생 발문을 공식 성취기준·공식 루브릭으로 부르지 않는다", 검증 사례 E16.
6. **해설 부족.** 세 MCP 본문 데이터는 성취기준 해설·적용 시 고려사항·평가 방향을 충분히 제공하지 않는다. 선택한 기준의 공식 PDF 주변 절을 함께 읽는 절차가 필요하다.
7. **검색 상한.** 세 서버의 검색 상한은 50개이며 성취기준 검색에 `offset` 페이지 인자가 없다. 50개를 전체로 오인하지 않는다. 오프라인 전체 확보는 고정 SHA JSON과 manifest 해시로 처리한다. 검증 사례 E20.

### 3.4 연동 계약 (구현 시 실제 스키마 재확인)

### 3.5 권리·한계

세 패키지 코드는 MIT다. 초등은 공공저작물 자유이용(저작권법 제24조의2), 중등·직업은 고시 원문의 보호대상 제외(제7조제2호)를 배포 근거로 제시한다. 이는 각 저장소의 권리 판단이며, PDF 지면·로고·글꼴이나 도서 저작권까지 포괄하는 허락으로 확대해 해석하지 않는다. 파생 그래프를 재사용하면 원저작자 고지를 보존한다.

조사 시점의 연결 도구 목록에서 지정된 세 MCP는 발견되지 않았다. 이 조사는 GitHub 데이터 조사·구조 계수·공식 PDF 표본 대조이며, Claude/Codex에서의 실제 MCP 연결 성공을 입증한 것은 아니다.

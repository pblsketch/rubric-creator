# 기존 채점기준표 개선 절차

교사가 이미 만든 루브릭·채점기준표를 진단하고 고칠 때 읽는다. 원칙은 `rubric-principles.md`와 같고, 여기서는 순서와 말하는 방식을 정한다.

## 원칙

- **원본을 보존한다.** 교사가 동의하지 않은 과제·배점·성취기준을 덮어쓰지 않는다. 개선안은 원본과 나란히 보여 준다.
- **의미 있는 기존 기준은 유지한다.** 전부 새로 쓰는 것이 개선이 아니다.
- **교사의 의도 → 표에서 확인되는 문제 → 학습·채점에 미치는 영향** 순서로 설명한다. "이 표는 틀렸다"가 아니라 "이 칸은 교사가 보려는 것 대신 이것을 재게 된다"로 말한다.
- **학생의 부족함과 루브릭 자체의 결함을 구별한다.** 기준끼리 모순되거나 과제가 증거를 낼 수 없으면 루브릭 결함이다.
- 학생 작업이 함께 오더라도 **그 학생을 채점하지 않는다.** 루브릭의 구별력을 점검하는 자료로만 쓴다.

## 절차

### 1. 원본 기록

표에서 다음을 뽑아 정리한다. OCR·사진으로 온 표는 병합 셀, 열 정렬, 숫자 판독을 확인하고 읽기 불명확한 곳을 표시한다.

- 평가요소(이름, 순서)
- 수준 수와 이름, 각 칸의 기술
- 배점·가중치·총점
- 교사가 유지하려는 제약(학교 양식, 총점, 단계 수)
- 성취기준·과제 정보가 있는지 여부

성취기준·과제 정보가 없으면 정렬(점검표 1·2번)은 "미확인"으로 두고 표 안에서 확인 가능한 문제(3–11번)만 진단한다. 필요하면 인터뷰로 보충한다.

### 2. 진단

`rubric-principles.md` 6절 점검표 11문항을 요소별·칸별로 적용한다. 발견한 문제는 **위치(요소·칸) → 무엇이 문제인가 → 학생·채점에 미치는 영향**으로 적는다.

자주 나오는 유형:

| 유형 | 모습 | 영향 |
|---|---|---|
| 과제 지시사항이 요소가 됨 | 표지, 분량, 그림 수, 참고자료 수 | 지시 따르기를 배움으로 셈. 최고점을 받아도 무엇을 이해했는지 모름 |
| 개수 세기 | "근거 3개 이상 / 2개 / 1개" | 질을 재지 않음. 관련 없는 근거 3개가 정확한 근거 1개보다 높음 |
| 축이 바뀜 | 상: 타당성 / 중: 개수 / 하: 제출 여부 | 학생이 무엇을 고쳐야 할지 모름 |
| 판정 용어만 있음 | "매우 잘함 / 잘함 / 보통 / 미흡" | 평정 척도. 교사마다 다르게 채점 |
| 요소 중복 | 같은 논리 오류를 내용·구성·표현에서 각각 감점 | 한 실수가 세 번 반영 |
| 여러 요소를 한 칸에 묶고 충족 개수로 등급 | "다음 5가지 중 4가지 충족 시 A" | 어떤 것을 못했는지 정보가 없음. 요소별 기술이 아님 |
| 사전에 알리지 않은 조건 | 안내에 없던 태도·발표 자세를 채점 | 학생이 대비할 수 없음 |
| 형식 요소에 큰 배점 | 디자인·깔끔함이 40% | 목표 배움의 비중이 작아짐 |
| 기대 이상 칸이 새 능력 | 도달 칸 + "추가 조사를 했다" | 가르치지 않은 것을 만점 조건으로 |

### 3. 요소별 제안

각 요소에 다음 중 하나를 붙인다.

- **유지** — 배움의 증거이고 기술도 같은 축. 그대로 둔다.
- **기술 수정** — 요소는 맞지만 칸의 표현을 고친다. 수정 전·후를 나란히.
- **통합 / 분리** — 겹치는 요소는 합치고, 두 가지를 재는 요소는 나눈다.
- **체크리스트로 이동** — 제출 조건·형식·학습 습관. 루브릭에서 빼고 별도 목록으로.
- **근거 추가 확인** — 성취기준·과제 정보가 있어야 판단할 수 있는 항목. 교사에게 묻는다.

### 4. 구조 결정

같은 총점·단계 수를 유지하는 개선이 가능한지 **먼저** 검토한다. 유지하면서 고칠 수 있으면 그 안을 먼저 낸다. 질적 차이를 그 단계 수로 구별할 수 없을 때만 구조 변경안을 추가로 낸다. 두 안이 있으면 둘 다 보여 주고 차이를 설명한다.

### 5. 개선안 제시

- 원본 → 개선안의 **중요한 차이와 이유**를 표로 보여 준다. 모든 글자 차이를 나열하지 않는다.
- 개선 후 배점이 바뀌면 기존 값과 제안 값을 나란히, 총점 일치를 확인한다.
- 학생용 성공 기준을 같은 요소 ID로 붙인다.
- 교사가 결정할 항목(과제 보완 여부, 형식 조건을 별도 평가할지)을 따로 적는다.

### 6. 경계 사례로 구별력 점검

두 수준 사이에 놓일 법한 작업을 **가상으로** 하나 만들어(또는 교사가 준 익명 작업으로) 개선된 기술이 그것을 한 칸에 놓을 수 있는지 본다. 놓을 수 없으면 기술을 다시 고친다. 이 단계의 결과는 "이 기술은 A와 B를 구별하지 못한다"처럼 **루브릭에 대한 진단**으로만 말한다. 교사가 준 작업의 학생에게 점수를 주지 않는다.

## 말하는 방식 예

> "‘자료 활용’ 요소의 중간 칸은 ‘자료 2개 사용’으로 되어 있습니다. 선생님이 보시려는 것은 자료 수가 아니라 자료가 주장을 뒷받침하는지로 보입니다. 지금 기술로는 관련 없는 자료 2개가 정확한 자료 1개보다 높게 나옵니다. 세 칸을 ‘자료가 주장을 얼마나 직접 뒷받침하는가’로 맞추는 안을 제안합니다. 총점 20점과 4단계는 그대로 둘 수 있습니다."

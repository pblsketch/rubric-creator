# 배점과 성적 반영 방식 설계

교사가 배점·환산표·여러 평가 증거의 종합 원칙을 요청할 때 읽는다. 근거는 `sources.md` G절. **규칙과 양식을 설계하며 실제 학생 제출물의 점수·등급을 산출하거나 성적을 확정하지 않는다.**

## 1. 무엇을 위한 평가인가

이미 제공된 정보는 활용하고, 빠진 목적과 학교 제약만 확인한다.

| 목적 | 설계할 것 |
|---|---|
| 학습 중 연습·자기평가 | 목표와 같은 기준, 피드백, 수정·재확인 기회. 연습 결과를 최종 점수에 자동 합산하지 않는다 |
| 성적 반영용 수행평가 | 배울 기회 이후에 어떤 개인 증거를 언제 수집할지, 사전에 알릴 기준과 점수 대응 |
| 반복된 평가 증거의 종합 | 성취기준별 기록, 척도 의미, 종합 방식과 경계 처리 원칙 |

과정평가를 모두 제외하지 않는다. 전략 점검·고쳐쓰기 자체가 목표이고 배울 기회가 주어졌다면 그 수행을 평가할 수 있다. 초안 제출·수정 횟수·노력의 양을 그 능력과 혼동하지 않는다.

## 2. 수준과 점수 연결

1. 요소별 목표 도달 수준을 먼저 확정한다. 4수준 중 3이 도달이라는 표시는 목표의 75%를 배웠다는 뜻이 아니다.
2. 학교의 총점, 최저점, 허용 점수 집합, 단계 수, 가중치, 기본점수·결시·미제출 규정을 기록한다. 모르는 값은 미확인으로 남긴다. 중·고 평가계획서용이면 기본점수 상한, 수행평가 영역 수, 급간 규칙, 성취수준 단계 수, [고] 추정분할점수·동점자 처리 여부도 적는다(`school-review.md`). 이 값들은 학교 결정 사항이며 스킬이 산출하지 않는다.
3. 각 점수가 어떤 수행을 나타내는지 대응을 설계한다. 다른 척도를 합칠 때는 의미가 대응하는지 확인한다. 임의의 미국 A–F 경계나 비례 환산을 적용하지 않는다.
4. 원본과 제안의 **최고점·최저점·가능한 점수 집합**을 비교한다. 합산형이면 가능한 수준 조합을 열거하고, 대응표라면 빠진 조합·겹치는 조건을 확인한다. 총점만 같다고 분포를 유지했다고 말하지 않는다.
5. 유지할 수 없는 제약은 바뀐 값과 이유를 표시한 구조 변경안으로 낸다. 학교 규정 자체를 스킬이 변경하지 않는다.

작은 번호 척도를 백분율로 환산하거나 단순히 만점을 크게 늘려도 성취 의미가 보존되지는 않는다. 백분율을 쓰는 평가라면 충분한 점수 분해능과 도달 기준을 함께 확인한다.

## 3. 여러 증거를 종합할 때

**한 과제의 요소 요약**과 **같은 성취기준의 반복 평가 종합**을 먼저 구분한다. 전자는 각 요소의 중요성과 학교 반영 방식을, 후자는 무엇을 어느 시점에 반복 확인했는지를 본다. 어느 경우에도 요소별 정보는 남긴다.

1. 성취기준·기준 ID별로 증거를 묶는 기록 틀을 만든다. 다른 목표의 자료를 같은 능력의 성장처럼 연결하지 않는다.
2. 과제·시점·증거 종류·척도 의미를 확인한다. 자료가 많아도 연습이나 무관한 과제를 포함하면 해석이 나빠진다. 같은 목표를 여러 방식으로 보여 줄 기회를 설계한다.
3. 순서가 있는 범주를 대표값으로 요약해야 한다면 **중앙값**을 검토한다. 서로 다른 척도에서 같은 번호라는 이유만으로 합치지 않는다. 가중치는 목표의 중요성과 수업의 강조점으로 설명한다.
4. 중앙 두 범주가 다르면 임의의 중간 성취수준을 새로 만들지 않는다. 학교의 경계 처리 규정에 따라 교사가 추가 성취 증거를 검토하도록 설계한다. 노력·태도를 경계 판정의 근거로 끼워 넣지 않는다.
5. 최근 증거를 중시하는 것은 **같은 성취기준**의 변화가 확인될 때다. 지속적인 향상·하락·일관성·불규칙성을 함께 살핀다. 가장 최근 한 건이나 최고 결과만 자동 채택하지 않는다. 다른 목표를 평가한 최근 과제가 이전 목표의 증거를 대체하지 않게 한다.
6. 증거가 부족하면 부족하다고 표시하고 추가 확인 기회를 설계한다. 스킬이 학생의 최종 등급을 결정하지 않는다.

형성평가 자료는 교사가 학습 상태를 이해하는 보조 증거가 될 수 있다. 그렇다고 처음에 비채점으로 안내한 연습을 사후에 점수화해 합산하는 것은 아니다.

## 4. 분리해 처리할 것

- **미관찰·미제출 / 관찰된 낮은 성취:** 전자는 증거 상태, 후자는 수행에 대한 판단이다. 상태와 학교의 행정적 점수 처리를 구분한다. 학교가 기본점수와 미제출·백지답안 점수를 요구하면 루브릭 표 밖 각주로 두고, 최하 수준 기술은 관찰된 수행으로만 쓴다.
- **학업 성취 / 제출·태도:** 별도 체크리스트로 옮긴 뒤 학업 점수에서 다시 감점하면 분리 효과가 사라진다. 학교가 감점을 정했다면 규정상 반영과 성취 해석의 한계를 함께 적는다.
- **모둠 결과 / 개인 증거:** 공동 산출물만으로 각자의 성취를 확인했다고 하지 않는다. 개인 수행·구술·기록 중 목표에 맞는 증거를 설계한다. 협력 자체가 목표면 그 행동을 별도 기준으로 본다.
- **제출 전 수정 / 평가 후 재제출:** 충분한 연습과 피드백을 먼저 계획한다. 재제출을 허용한다면 이유·기한·추가 학습·새 증거·반영 방식은 교사/학교가 정한다. 답이 알려진 시험의 재평가는 같은 목표를 보는 다른 문항이 필요할 수 있다.
- **성적 산출용 세분화 / 의미 있는 구별:** 동점자 방지를 위한 점수 분해능은 요소 수·영역 수·가중치 차등으로 확보한다. 한 요소의 수준을 의미 없는 칸으로 쪼개거나 개수·분량 조건을 다시 넣지 않는다.

## 5. 출력과 확인

요청 범위에 맞게 다음 가운데 필요한 것만 낸다.

- 평가 단계별 목적·증거·피드백/수정 시점·성적 반영 여부.
- 수준–점수 대응표와 원본/제안의 점수 범위 비교.
- 성취기준별 증거 기록용 빈 틀: 기준 ID / 시점 / 과제 / 증거 종류 / 성적 반영 목적 / 확인 필요 사항.
- 교사가 결정할 가중치·경계 처리·미제출·재평가 규정.

내기 전에는 도달 의미가 환산으로 바뀌지 않았는지, 수준 조합에 빈틈이 없는지, 연습·태도·다른 목표의 자료가 섞이지 않았는지 확인한다. 학생 자료 없이 가능한 것은 **설계 규칙의 점검**이다.

# 교과·학교급별 조정

평가요소 고정 목록이 아니다. 해당 교과 부분만 읽고, 항상 실제 성취기준과 교사가 가르친 내용을 우선한다.

## 교과별로 볼 증거와 피할 오용

| 영역 | 살펴볼 학습 증거 | 피할 오용 |
|---|---|---|
| **국어·외국어** | 목적·독자에 맞는 의미 구성, 해석의 근거, 실제 상호작용(듣고 반응하기), 의사소통의 효과 | 문법 오류 수·발화량·분량만으로 전체 수행 판단. 내용 요소 없이 형식·어법만 있는 표 |
| **수학** | 개념과 표상 사이의 관계, 전략 선택의 적절성, 계산의 정확성과 추론·정당화, 수학적 의사소통 | 풀이가 길다는 이유로 높은 수준. 정당한 다른 풀이 배제. 답만 맞으면 만점 |
| **과학** | 탐구 질문의 명료성, 설계 판단(변인·통제), 자료 처리, 증거와 결론의 연결, 한계 인식 | 보고서 칸을 채운 개수, 가설 적중 여부를 이해와 동일시. 표지·그림 꾸밈 |
| **사회·역사·도덕** | 자료의 맥락·관점 파악, 관계·인과 설명, 가치 판단의 근거, 다른 입장 고려 | 교사의 견해와 일치하는 정도, 출처 수만 채점 |
| **예술(음악·미술)** | 표현 의도와 선택, 매체·기법의 기능, 작품·수행에서 확인되는 효과, 감상의 근거 | 막연한 "예쁨/창의적임". 설명 글로 실제 수행 대체. "창의성" 요소가 실제로는 꾸밈 |
| **체육** | 실제 기능·전략, 상황 판단, 안전·협력의 관찰 행동, 자기 수행 조절 | 체력·체형·참여량으로 목표 기능 대체. 태도 점수로 기능 점수 상쇄 |
| **기술·가정·정보** | 설계 제약의 반영, 작동, 사용·검증, 수정의 근거, 절차의 안전 | 결과물이 작동했다는 한 조건으로 과정 전체 추정. 코드 줄 수·기능 개수 |
| **직업 전문교과** | 직무 조건에 맞는 절차·품질·정확성·안전·문제 대응, 규격 충족 | 글 잘 쓰기를 실무 능력으로 대체. 임의의 산업 규격 생성. 정량 기준을 무조건 제거 |
| **통합교과(초1·2)** | 교사의 관찰·구술·행동 증거, 놀이·활동 속 참여 방식 | 읽기·쓰기 부담이 큰 자기평가지. 결과물 완성도 |

## 정량 기준이 정당한 경우

용접 비드 폭·두께, 측정 오차 범위, 조리 온도·시간, 안전 절차 이행 여부, 공인 규격 충족처럼 **수치가 목표 자체**인 경우는 정량 기준을 유지한다. 규격은 교사 제공·공인 값만 쓰고 스킬이 지어내지 않는다. 이 경우에도 "규격 충족(예/아니오)"과 "그 위의 품질(균일함, 마무리)"을 나누어 앞은 체크리스트, 뒤는 루브릭으로 둘 수 있다.

## 학교급별

- **초등 저학년** — 교사 관찰·구술·행동 증거를 활용한다. 학생용 자료는 그림·짧은 문장·예/아니오 질문 수준으로 줄이되, 목표 자체를 낮추지 않는다.
- **초등 고학년·중학교** — 학생이 자기 언어로 루브릭을 다시 말할 수 있는지가 활용의 출발점이다.
- **고등학교** — 정확한 과목명(공통/일반선택/진로선택/융합선택)을 유지한다. 성취기준 코드가 과목마다 다르다.
- **특성화고** — 보통교과와 전문교과의 성취기준 출처가 다르다(`curriculum.md`). 실무 과목은 NCS 능력단위와 연결될 수 있으나 교사가 제공한 것만 쓴다.

## 모둠·개인

모둠 결과물만으로 개인의 배움을 평가하지 않는다. 개인의 증거(역할 산출물, 개인 성찰, 구술 확인)가 없으면 "개인 증거 부족"으로 표시하고 과제 보완을 제안한다. 협력 자체가 성취기준의 목표라면 관찰 가능한 협력 행동을 요소로 둘 수 있다.

## 표현 방식과 지원

- 목표가 과학 이해라면 구술·그림으로 표현하는 것을 허용할 수 있다. 목표가 글쓰기 자체라면 구술로 대체하고 동등하다고 단정하지 않는다.
- 장애·언어 지원(보조 도구, 시간 연장, 통역)을 사용했다는 이유로 낮은 수준을 주지 않는다. 지원은 표현 장벽을 낮추는 것이지 목표를 바꾸는 것이 아니다.
- 개별화된 별도 목표가 있으면 그 목표를 명시하고 그에 맞는 기술을 쓴다.

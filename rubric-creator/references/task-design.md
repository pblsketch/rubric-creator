# 수행과제 재설계 (GRASPS)

과제를 새로 만들거나 다시 짤 때 읽는다. 백워드 설계(Wiggins & McTighe)의 수행과제 설계 도구 GRASPS를 2022 개정 교육과정 용어에 맞춰 재구성했다. 근거는 `sources.md` D절.

용어는 교육과정 문서를 따른다: **핵심 아이디어**(영역의 학습을 통해 일반화할 수 있는 내용, 학습자가 성취하기를 기대하는 결과), **내용 요소**(지식⋅이해 / 과정⋅기능 / 가치⋅태도), **성취기준**, **성취기준 해설**, **성취기준 적용 시 고려 사항**, **평가의 방향·평가 방법**, **성취수준**.

## 0. 언제 이 절차로 들어가는가

- 교사가 과제를 새로 만들거나 다시 짜 달라고 할 때("수행과제 만들어 줘", "더 실제적인 과제로")
- 성취기준만 있고 과제가 없을 때
- 정렬 점검에서 과제가 성취기준의 증거를 내지 못할 때 → 교사에게 재설계를 제안하고 동의하면 진입
- 아래 4절 타당성 점검에서 "가능성 높음"이 나올 때

**이 절차의 목적은 흥미로운 프로젝트가 아니라 타당한 증거다.** 재미있는 과제 요청에도 "이 과제가 성취기준의 증거를 내는가"를 먼저 묻는다.

## 1. 바라는 결과 정리

과제를 만들기 전에 무엇의 증거를 얻으려는지 적는다.

| 항목 | 출처 | 비고 |
|---|---|---|
| 성취기준 | 교사 제공 / MCP 조회(`curriculum.md`) | 코드·원문·상태 |
| **핵심 아이디어** | 교사 제공 또는 해당 교과 교육과정 문서의 내용 체계 표 | **MCP 데이터에는 없다.** 교사가 모르면 "해당 영역의 내용 체계 표에서 확인"을 요청하고, 없으면 성취기준 문장에서 잠정 일반화를 쓰되 "잠정"이라고 표시 |
| 이번 과제에서 다룰 내용 요소 | 성취기준 해설, 교사가 가르친 내용 | 지식⋅이해 / 과정⋅기능 / 가치⋅태도 가운데 실제로 가르치고 관찰할 것만 |
| 단원의 탐구 질문(선택) | 교사가 정해 둔 것이 있을 때만 | 교육과정 문서의 용어가 아니므로 요구하지 않는다 |

핵심 아이디어는 "학생이 단원을 마친 뒤 새 상황에서도 쓸 수 있어야 하는 일반화"다. 과제는 이 일반화를 **써서** 무엇인가를 해내게 해야 한다. 사실을 옮겨 적는 과제는 핵심 아이디어의 증거가 아니다.

## 2. 필요한 증거 정하기

"목표한 배움을 보여 주는 학생은 …할 수 있다"를 2–4개 쓴다. 아래는 이해·추론이 목표일 때 살펴볼 모습이다. 이유·판단 과정이 목표라면 그 증거를 확보한다. 기능·표현·안전 수행 자체가 목표라면 **실제 수행 관찰을 우선**하고 목표 밖 설명 글을 필수로 붙이지 않는다. 필요한 설명도 구술·시연·표시 등 목표에 맞는 방식으로 받는다. 증거 부족을 곧 이해 부족으로 단정하지 않는다.

| 이해의 모습 | 학생이 할 수 있는 것 | 과제 유형 예 |
|---|---|---|
| 설명 | 자기 말로 원리를 설명하고 근거를 대며 예측한다 | 원리를 모르는 사람에게 가르치는 자료, 이유를 밝힌 제안서 |
| 해석 | 자료·텍스트·상황의 의미를 읽어 내고 맥락을 붙인다 | 자료로 경향 찾기, 작품의 의미 해석 |
| 적용 | 새 상황·제약 속에서 지식을 써서 문제를 푼다 | 조건이 있는 설계·계획·해결 |
| 관점 | 다른 입장을 드러내고 전제·한계를 짚으며 비판적으로 본다 | 상반된 자료 비교, 입장 정당화 |
| 공감 | 다른 처지의 사람이 어떻게 느끼고 생각하는지 헤아린다 | 역할 편지, 당사자 관점의 기록 |
| 자기 지식 | 자기 사고와 수행을 점검하고 조정한다 | 자기 평가 후기, 수정 과정 기록 |

**현재 과제가 있으면 세 가지를 점검한다.**

1. **목표와 요구가 맞는가.** 정해진 절차의 정확성·숙련이 목표라면 그 수행을 관찰한다. 전략 선택·추론·정당화가 목표인데 정해진 절차를 따라 하는 것만으로 끝난다면 과제 보완이 필요하다. 수업 중 연습은 학습에 필요한 기회다. 과제의 복잡성과 연습/성적 반영의 목적을 혼동하지 않는다.
2. **타당성 두 질문.** (가) 학생이 이 과제를 잘 해내고도 목표한 이해를 보여 주지 못할 수 있는가? (나) 이해가 깊은 학생이 이 과제에서 못할 수 있는가? 하나라도 "그렇다"면 증거가 아니다.
3. **사고 요구.** 성취기준이 요구하는 사고와 과제가 시키는 사고가 같은가(`dok.md` 5절).

## 3. GRASPS로 과제 틀 잡기

먼저 핵심 아이디어(또는 성취기준)를 확인할 **질문 또는 수행 지시 한 줄**을 쓴다. 그다음 이를 더 실제적인 상황에서 다루는 과제를 만든다. **상황이 억지스러우면 GRASPS를 쓰지 않고, 목표에 맞는 서술형·실기 과제 + 성공 기준 사전 공개로 설계한다.** 모든 수행평가가 GRASPS일 필요는 없다.

여섯 요소를 순서대로 채우되 **필요한 칸만** 채운다. 역할·청중·산출물은 **2–3안**을 만들어 교사가 고르게 한다.

| 요소 | 채우는 문장 | 지킬 것 |
|---|---|---|
| **G 목표** | "당신의 과제는 …", "해결할 문제는 …", "넘어야 할 제약은 …" | 시나리오 안의 목표다. 성취기준 문장을 그대로 넣지 않는다 |
| **R 역할** | "당신은 …입니다", "…을 요청받았습니다" | **그 교과를 실제로 쓰는 사람**(실무자·시민·당사자). 장식용 역할(요리사가 분수 계산만 한다)은 피한다. 특성화고는 직무에서 나온다 |
| **A 청중** | "결과물을 받을 사람은 …", "설득할 대상은 …" | 결과물로 무엇인가를 **판단·결정하는 사람**. 실제 청중이 어려우면 가상 청중을 분명히 정한다. "선생님"은 청중이 아니다 |
| **S 상황** | "당신이 처한 상황은 …", "다루어야 할 조건은 …" | 판단이 필요한 이유가 되는 **제약·조건·잡음**(예산, 시간, 상충하는 요구, 불완전한 자료) |
| **P 산출물·수행과 목적** | "…을 만들어서 …하도록", "…을 개발해서 …할 수 있게" | **목적이 붙어야 한다.** 형식만 있는 지시("보고서 작성")는 다시 쓴다. 목표가 이유·추론을 요구하면 그 증거를, 기능 수행이면 실제 수행 증거를 확보한다 |
| **S 성공 기준** | "당신의 결과물은 …해야 합니다", "…로 판단됩니다" | **목표 도달의 질**을 설명하고 루브릭의 요소 ID로 연결한다. 한 요소를 여러 학생용 질문으로 풀 수 있다. 형식·분량은 체크리스트로 |

### 역할·청중·산출물 후보 (한국 학교 맥락)

교과별로 그 교과를 실제로 쓰는 사람에서 고른다. 목록은 출발점이며 교사와 학생의 현실에 맞게 바꾼다.

| 영역 | 역할 후보 | 청중 후보 | 산출물 후보 |
|---|---|---|---|
| 국어·외국어 | 기자, 편집자, 해설자, 통역·안내 담당, 캠페인 기획자 | 독자층(후배·학부모·지역 주민), 편집회의, 방문객 | 기사, 안내문, 서평, 연설, 인터뷰, 팟캐스트 대본 |
| 수학 | 설계 담당, 예산 담당, 데이터 분석가, 검수자 | 결정권자(학생회·학교·가상 회사), 의뢰인 | 견적·계획서, 도면과 계산 근거, 자료 분석 보고, 판정 의견서 |
| 과학 | 연구원, 검사원, 환경 조사원, 안전 점검자 | 검사 의뢰 기관, 지역 사회, 후배 학년 | 실험 설계서, 조사 보고, 문제 해결 안내서, 검증 결과 |
| 사회·역사·도덕 | 정책 제안자, 큐레이터, 조사관, 시민 단체 활동가 | 지자체·학교 운영위, 전시 관람객, 편집 위원 | 정책 제안서, 전시 해설, 사료 기반 서술, 입장문 |
| 예술 | 창작자, 큐레이터, 음악 감독, 디자이너 | 관객, 의뢰인, 전시 기획팀 | 작품 + 의도 설명, 프로그램 노트, 비평 |
| 체육 | 코치, 트레이너, 경기 분석가, 안전 요원 | 팀원, 의뢰인, 대회 운영진 | 훈련 계획, 경기 전략 분석, 시범 + 설명 |
| 기술·가정·정보 | 설계자, 개발자, 생활 설계 컨설턴트 | 사용자, 의뢰인, 검수자 | 시제품 + 설계 근거, 사용 설명서, 개선 보고 |
| 직업 전문교과 | 해당 직무 담당자(정비사, 조리사, 간호 보조, 네트워크 관리자 등) | 고객, 상급자, 검사 기관 | 작업 결과물 + 작업 기록, 점검표, 고객 안내 |

## 4. 타당성 점검

시나리오를 만든 뒤 아래 일곱 항목을 채운다. 목표는 모두 "가능성 낮음"이다. "높음"이 있으면 시나리오를 고친다.

| # | 학생이 다음만으로 이 과제를 잘 해낼 수 있는가? | 낮음 / 보통 / 높음 |
|---|---|---|
| 1 | 이해가 얕아도 영리한 추측으로 | |
| 2 | 배운 것을 그대로 옮겨 적어서(재생) | |
| 3 | 열심히만 해서(노력·성실) | |
| 4 | 예쁜·화려한 산출물로 | |
| 5 | 타고난 말솜씨·글솜씨로 | |
| # | 이해가 깊은 학생이 다음 이유로 못할 수 있는가? | |
| 6 | 과제가 성취기준과 무관해서 | |
| 7 | 기준이 자의적이어서(형식·태도가 큰 비중) | |

추가 확인:
- **개인 증거.** 모둠 과제면 개인의 이해를 볼 단계(개인 설명, 역할 산출물, 성찰)가 있는가.
- **한국 수행평가 조건.** 중·고 평가계획 점검은 수업 시간 외에 수행한 산출물을 채점하는 과제형 수행평가와 사전 준비가 필요한 암기식 수행평가를 금지한다(`school-review.md`). 외부 실제 청중 대신 가상 청중, 집에서 하는 조사·작성 대신 교실 내 단계로 나누고, 여러 차시가 필요하면 차시마다 무엇을 관찰·수집하는지 적는다. 개인 평가·공정성 요구에는 개인 증거 단계를 둔다.
- **자유 선택의 범위.** 주제·형식 선택이 넓을수록 증거가 흐려질 수 있다. 성취기준의 증거가 나오는 범위 안에서 선택을 준다.

## 5. 루브릭으로 연결

- S(성공 기준)를 정렬표의 "평가요소 후보"로 옮긴다. **과제 안내문과 루브릭이 같은 배움을 평가해야 한다.** 요소 ID를 연결하고, 학생용 문장을 풀어 쓰더라도 새로운 평가 조건은 더하지 않는다.
- 이후는 `rubric-principles.md` 절차 그대로: 요소 조건 점검 → 목표 도달 수준 먼저 → 같은 축 → 학생용 성공 기준 → 배점(요청 시).
- 루브릭에도 타당성 두 질문을 적용한다. 기준을 충족하고도 이해가 없을 수 있는가? 기준을 못 채우고도 이해를 보일 수 있는가?

## 6. 산출물

1. **학생용 과제 안내문**(한 쪽): 목표 · 역할 · 청중 · 상황 · 산출물과 목적 · 성공 기준. 성공 기준은 루브릭의 요소 ID로 연결한다.
2. **교사용 설계 근거**: 성취기준·핵심 아이디어·내용 요소, 필요한 증거(2절), 타당성 점검 결과(4절), **원래 과제와 바뀐 점과 이유**(원래 과제가 있을 때).
3. 루브릭(기존 출력).
4. 제출 조건 체크리스트.

## 7. 지킬 규칙

- GRASPS를 강요하지 않는다. 억지스러우면 목표에 맞는 서술형·실기 과제 + 기준 공개.
- 흥미 ≠ 증거. 재미는 증거를 확보한 뒤 더한다.
- 역할·청중은 교과 실무·시민 생활에서. 역할극 자체가 목적이 되지 않게 한다.
- 산출물에는 목적과 **목표 능력을 확인할 증거**가 있어야 한다.
- S와 루브릭 평가요소는 같은 배움을 보고 ID로 연결한다.
- 원래 과제를 보존하고, 재설계안은 나란히 보여 준다. 교사가 동의하지 않은 과제를 덮어쓰지 않는다.
- 학생 제출물 채점 금지 원칙은 그대로다.

## 8. 작은 예시 (이 스킬을 위해 새로 작성)

중학교 과학, 성취기준의 요구가 "변인을 통제한 실험을 설계하고 결과를 근거로 결론을 내린다"이고 핵심 아이디어가 "과학적 탐구는 증거에 근거한 설명을 만드는 과정"이라고 하자. 원래 과제는 교과서 실험을 따라 하고 보고서 칸을 채우는 것이었다(연습). 재설계:

- **G** 학교 매점에서 팔 보온 도시락 가방 두 종 가운데 어느 것이 더 오래 온도를 유지하는지 판정한다.
- **R** 학생회 구매 검토 담당.
- **A** 구매를 결정할 학생회 임원과 매점 운영자.
- **S** 예산이 한 종류만 허용하고, 판매자 자료는 서로 다른 조건으로 측정한 것이라 믿을 수 없다.
- **P** 두 가방을 같은 조건에서 비교하는 실험을 설계·수행하고, 결과와 한계를 담은 검토 의견서를 작성해 구매 결정을 돕는다.
- **S** 의견서는 (1) 비교에 영향을 주는 변인을 찾아 통제했는지, (2) 측정이 판정에 필요한 만큼 정확·반복되었는지, (3) 결론이 자료로 뒷받침되고 한계가 밝혀졌는지, (4) 결정권자가 읽고 판단할 수 있게 전달되었는지로 판단한다.

이 S 네 문장이 루브릭의 평가요소 넷이 된다. 가방 디자인, 보고서 표지, 분량은 기준에 없다.

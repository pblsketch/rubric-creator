# 학습에서 루브릭 쓰기, 교사 간 기준 맞추기

교사가 수업 활용·자기평가·동료평가 자료, 또는 동료 교사와의 채점 기준 조정을 요청할 때 읽는다. 근거는 `sources.md` F·G절. 스킬은 교사가 사용할 활동·질문·빈 양식을 설계하며 **학생 제출물의 점수·등급이나 개별 피드백을 대신 작성하지 않는다.**

## 1. 왜 필요한가

좋은 표만으로 학습 효과가 생기지 않는다. 학생이 기준을 이해하고 자기 작업에서 근거를 찾아, 피드백 뒤에 수정·유지를 결정하고 실행 결과를 다시 확인하도록 설계한다. 사전 공유 자료에서 정답을 노출하는 채점 메모는 분리한다(`rubric-principles.md` 4절).

기존 루브릭에서 이번 차시에 사용할 기준 ID를 고른다. 단원의 모든 요소를 매번 점검할 필요는 없다. 이미 받은 목표·시간·학생 경험을 활용하고 필요한 정보만 보충한다.

| 이번 차시의 학습목표 | 다룰 내용 | 배움을 드러내는 활동 | 학생이 작업에서 찾을 특징(기준 ID) |
|---|---|---|---|
| | | | |

목표 문장만 나누어 주지 않는다. 활동을 하며 기준을 적용하고 진전을 확인할 수 있어야 한다.

## 2. 학생용 성공 기준

교사용 기준표의 각 평가요소를 같은 ID로 학생용으로 옮긴다. 한 요소를 질문 여러 개로 풀 수 있지만 새 평가 조건을 더하지 않는다.

- **형식**: 요소마다 "도달"의 모습을 1인칭 확인 문장으로. "나는 내가 든 자료가 왜 이 원인을 보여 주는지 설명했다."
- **쉬운 말로 바꾸되 목표를 낮추지 않는다.** "정당화"를 "이유 대기"로 바꿀 수는 있지만 "이유를 자료로 뒷받침하기"라는 요구는 유지한다.
- 초등 저학년은 그림·구술·시연, 중학교 이상은 짧은 자기점검 질문을 활용한다. 언어 표현이 목표가 아니라면 긴 설명 글을 요구하지 않는다.
- 정답·필수 개념 목록은 넣지 않는다(교사용 채점 메모로 분리).

## 3. 학생이 기준을 이해하는지 확인하는 활동 (교사에게 제안)

- **자기 언어로 다시 쓰기**: 짝과 요소 하나씩 읽고 "이 칸은 무슨 뜻인가"를 자기 말로 쓴다. 학생이 만든 문장은 루브릭을 더 명확하게 고치는 자료가 된다.
- **헷갈리는 점 묻기**: 요소별로 이해되지 않는 낱말·조건을 모아 학급 전체가 논의한다.
- **예시 작품과 연결**: 익명·가상 예시 2–3개를 수준 칸에 놓아 보게 한다. 왜 그 칸인지 근거를 말하게 한다.
- **과제 전·중·후 짝 점검**: 시작 전 기준 설명, 중간에 "지금 내 작업이 어느 칸인가", 제출 전 "무엇을 수정하거나 유지했고 그 이유는 무엇인가".
- **함께 만들기**: 익숙한 종류의 과제라면 예시 작품의 잘된 점·부족한 점을 브레인스토밍하고 배움의 속성으로 묶어 요소를 합의한다. 교사는 학생이 표지·글씨 같은 표면 속성 대신 배움의 속성으로 가도록 이끈다.

교사는 학생이 든 근거가 기준과 연결되는지 확인하고 오해한 낱말·조건을 다시 설명한다. 자기평가가 처음이면 먼저 자기 작업으로 기준을 적용하고 이유를 말하는 연습을 한다. 교사가 그 판단에 피드백을 준 뒤 동료평가로 확장한다. 경험이 있는 학생은 필요한 확인만 하고 진행한다.

## 4. 자기평가·동료평가 양식

교사용과 같은 요소 ID와, 수준을 표시할 경우 같은 수준 이름을 쓴다. 다음은 도서 양식을 복제하지 않고 새로 만든 빈 틀이다.

| 기준 ID | 현재 작업에서 찾은 근거 | 개선·유지할 점과 이유 | 사용할 전략 | 다시 확인할 시점 | 이후 작업에서 확인한 변화 |
|---|---|---|---|---|---|
| | | | | | |

- "근거" 칸을 반드시 둔다. 칸에 동그라미만 치는 양식은 판정이지 학습이 아니다.
- 동료평가는 "점수 주기"가 아니라 "근거 찾아 주기 + 질문 하나"로 설계한다.
- 교사는 자기평가 결과를 성적에 직접 반영하지 않는다고 안내한다(정직한 자기평가를 위해).

동료평가 규범은 사람 대신 작업을 설명하기, 기준과 연결한 강점·질문·제안 주기, 상대의 설명 듣기다. 제안을 받은 학생이 **수정 또는 유지**를 결정하고 기준으로 이유를 설명한다. 친구의 제안을 모두 따르거나 변경량을 늘려야 좋은 성찰이 되는 것은 아니다. 기준 적용이 어렵거나 학생이 불편해하면 익명 예시·자기 작업으로 돌아가 연습한다.

### 실행 뒤 다시 확인

1. 학생이 현재 목표와 작업 사이의 간격에 맞는 작은 목표와 전략을 정한다. '점수 올리기', '더 열심히'만 적으면 무엇을 어떻게 할지 다시 묻는다.
2. 같은 작업을 수정하거나 다음 유사 과제에 적용할 시간을 정한다. 이미 기준을 충족한 부분은 근거를 들어 유지할 수 있다.
3. 학생은 실행 뒤 같은 기준으로 증거를 다시 찾는다. 변화가 없으면 기준 이해·전략의 적합성·연습 기회를 점검한다.
4. 교사는 공통 오해에는 재설명·소그룹 연습을, 일부의 어려움에는 필요한 개별 지원을 계획한다. 계획과 실제 확인 결과를 구분해 기록한다.

## 5. 피드백 문구 자료 (교사용)

스킬은 교사가 쓸 수 있는 **확인할 증거 → 질문 → 반응에 따른 지원 → 재확인**을 만든다. 학생이 직접 생각할 수 있는 질문과 빈 도구를 제공하고 학생 글의 대체 문장이나 완성 답안을 제공하지 않는다.

| 요소 | 관찰 질문(교사가 작업을 보며) | 반응에 따른 지원과 재확인 |
|---|---|---|
| 근거와 설명의 연결 | 이 자료와 원인 설명을 연결하는 부분은 어디인가? | 주제만 같다고 답하면 자료가 보여 주는 사실과 설명을 나누어 표시하게 하고 연결을 다시 확인 |

피드백은 학생이 사용할 시간이 있을 때 준다. 한 번에 다 고치게 하지 않고 목표와 학생에게 중요한 지점을 고른다. 강점도 기준과 근거로 설명한다. 질문 뒤에는 생각하고 답할 시간을 둔다. 읽기·표현 부담과 목표에 따라 구술·글·시연을 선택한다. 연습·초안·최종 제출의 성적 반영이 쟁점이면 `grading-use.md`를 읽는다.

## 6. 교사 간 채점 기준 맞추기

동료 교사와 채점이 갈릴 때. 목적은 **루브릭 기술을 고치는 것**이지 특정 학생의 점수를 확정하는 것이 아니다. 평가계획의 교차채점 계획을 실행하는 절차로도 쓴다.

절차:
1. 교사들이 각자 익명 작품 2–3개를 요소별로 어느 칸에 놓았는지, **그 칸을 고른 근거(작품의 어느 부분)**를 적는다.
2. 갈린 요소를 찾는다. 갈림의 원인을 분류한다.
   - 기술이 두 가지로 읽힘 → 기술 수정
   - 기술에 없는 조건을 한 교사가 적용함 → 조건을 드러내고 넣을지 결정
   - 작품이 두 칸 사이에 걸침 → 경계 사례 설명을 기술에 추가
   - 요소 경계가 겹침 → 요소 분리·통합
3. 수정한 기술로 같은 작품을 다시 놓아 보고 가능하면 다른 익명 작품에서도 구별이 유지되는지 확인한다.
4. 남는 차이는 "전문적 판단의 여지"로 인정하고 경계 사례 예시를 기록으로 남긴다.

스킬의 출력: 갈린 요소, 원인 분류, 수정된 기술, 경계 사례 설명. **작품에 대한 점수는 내지 않는다.**

## 7. 말하지 않을 것

내기 전에 기준의 의미와 ID 연결, 이해 확인 활동, 학생의 수정·유지 선택, 실행 시간·재확인 증거·교사의 다음 조치, 성적 반영과의 구분이 있는지 점검한다.

- 학생 작업이 없거나 가상인데 "학습 효과·신뢰도를 확인했다"고 하지 않는다.
- 자기평가 양식을 만들었다고 학생이 기준을 이해했다고 하지 않는다. 이해 확인은 3절 활동에서 이루어진다.
